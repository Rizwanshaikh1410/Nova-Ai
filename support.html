Support

Need help, found an incorrect detail, or want to submit a new AI tool? You're in the right place. Use the contact form or follow the support options below.

Suggest a New AI Tool

You can suggest any AI tool that you think should be listed on Nova AI.

  1. Go to the Contact page.
  2. Send the tool name, official website link, category, and a short description.
  3. Our team will review and verify the details.
  4. Approved tools are added within 24–72 hours.

Report Incorrect Information

If you find a mistake (wrong link, outdated pricing, wrong category, etc.), report it using the contact form.

  • Mention the tool name
  • Share the incorrect detail
  • Share the page URL (if possible)

We correct verified issues quickly.

Broken Link Support

If a link is not opening or showing an error:

  • Send the tool name
  • The link that is broken
  • The page where you found it

Broken links are usually fixed within a few hours.

FAQ

Q: Are these links official?
A: Yes. We verify and only add official product websites. If you find an incorrect link, report it via Contact.

Q: Do you own any of these tools?
A: No. Nova AI is only a directory. All tools belong to their respective owners.

Q: How long does it take for a tool suggestion to be added?
A: Normally within 24–72 hours after verification.

Q: Can I request sponsored placement?
A: Yes, you can contact us for sponsored listings. All sponsored tools are clearly marked.

Q: What if a tool changes pricing or features?
A: Tool owners frequently update their platforms. If you see outdated info, report it and we’ll update it.

Q: Can developers request updates to their own tool pages?
A: Yes. Tool owners can request updates anytime by contacting us with proof of ownership.

Contact & Response Time

  • General Queries: 24 hours
  • Tool Suggestions: 24–72 hours
  • Broken Links: Same day (usually within a few hours)
  • Sponsored Listing Requests: 24 hours

Important Notes

  • Nova AI does not guarantee accuracy of third-party tools.
  • We regularly update listings but some information may change on external websites.
  • All AI tools belong to their respective owners and companies.
  • We do not provide technical support for third-party tools — contact their official support teams.
